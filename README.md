# first-pages-ecommerce# First Pages — Personalized Children's Books

**Live website:** https://firstpages.store/  
**Portfolio:** https://brendanmmcnamara.com/

## Project overview
First Pages is an e-commerce experience for personalized children's books. This repository presents the product's visual design, user experience, and WordPress/WooCommerce implementation as a portfolio case study.

## UX and design focus
- Customer journey from discovering the product to checkout
- Information architecture, navigation, and responsive layouts
- Product personalization and photo-upload experience
- Checkout usability and clear calls to action
- Warm, gift-focused brand storytelling
- AI-assisted research, ideation, copy exploration, and design iteration

## Platform
- WordPress
- WooCommerce
- Bookworm theme
- Selected customizations (to be documented after code review)

## Planned case-study documentation
- Screenshots and annotated interface walkthroughs
- Customer journey and checkout flow
- Design rationale and iteration history
- Selected custom code and implementation notes

## Repository status
**Documentation in progress.** Source files and case-study assets will be added after review. This repository is not intended to contain a complete WordPress installation or backup.

## Privacy and security
Do not upload `wp-config.php`, credentials, API keys, database exports, customer/order records, private uploaded photos, or third-party theme/plugin code without redistribution rights.
